# 傻瓜翻译

首次安装，按 Mac 的芯片和系统选择对应版本。

- [下载 CC 版](https://github.com/abgrund233-stack/foolish-translation-updates/releases/latest/download/FoolishTranslation-cc.zip) · macOS 11.7 或更新版本，支持 Intel 和 Apple 芯片。
- [下载通用版](https://github.com/abgrund233-stack/foolish-translation-updates/releases/latest/download/FoolishTranslation-apple.zip) · macOS 14 或更新版本，适用于 Apple 芯片。

解压后把应用拖到「应用程序」文件夹。自 1.1.23 起，点应用内「系统设置 → 常规 → 检查并更新」即可获取当前版本对应的更新。发现新版后，应用会自动下载、验证、安装并重启。
